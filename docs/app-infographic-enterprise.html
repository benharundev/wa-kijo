Platform Layers

Structure

1. Experience Layer

Next.js web app for auth, onboarding, dashboard, org settings, and billing UX.

2. API Core Layer

NestJS modules for contacts, conversations, billing, email, health, and auth orchestration.

3. Data & Shared Layer

Prisma models/migrations and shared Zod DTO + permission types across API and Web.

4. Integration Layer

Stripe, Resend, Redis/BullMQ, and observability pipeline connected to core services.

Secure Request Lifecycle

Control Plane
Step 1: Context InitializationFastify hook creates request scope with requestId and context placeholders.
Step 2: Auth InterceptBetter Auth handles `/api/auth/*` directly for raw cookie/session flows.
Step 3: Guard EnforcementAuthGuard resolves active org, PermissionGuard enforces role capabilities.
Step 4: Tenant-Scoped Data AccessBaseRepository injects orgId filters and soft-delete defaults automatically.
Step 5: Uniform API ContractConsistent success/error response envelope for client reliability and monitoring.
